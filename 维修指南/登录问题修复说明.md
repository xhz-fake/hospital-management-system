# 登录密码错误问题修复说明

## 🔍 问题分析

### 问题现象
- 输入用户名 `doctor1` 和密码 `123456` 时显示"密码错误"
- 后端日志显示已成功查询到用户，但密码验证失败

### 问题原因
1. **数据库中的密码存储格式**：数据库中存储的密码是 **MD5加密后的值**
   - 例如：`e10adc3949ba59abbe56e057f20f883e`（这是 `123456` 的MD5值）

2. **后端代码问题**：原来的 `DoctorServiceImpl.java` 中直接比较明文密码和MD5值
   ```java
   // 错误的代码（修复前）
   if (!doctor.getPassword().equals(password)) {
       throw new RuntimeException("密码错误");
   }
   ```
   - 前端传来的密码：`123456`（明文）
   - 数据库中的密码：`e10adc3949ba59abbe56e057f20f883e`（MD5）
   - 两者直接比较，永远不可能匹配！

---

## ✅ 解决方案

### 修复内容
1. **创建了 MD5 工具类**：`MD5Util.java`
   - 位置：`HospitalManagementSystem_backend/src/main/java/com/hospital/util/MD5Util.java`
   - 功能：将明文密码转换为MD5加密值

2. **修改了登录验证逻辑**：`DoctorServiceImpl.java`
   - 修改前：直接比较明文密码和MD5值
   - 修改后：先将输入的明文密码进行MD5加密，再与数据库中的MD5值比较

### 修复后的代码逻辑
```java
// 修复后的代码
if (!MD5Util.verify(password, doctor.getPassword())) {
    throw new RuntimeException("密码错误");
}
```

**工作流程：**
1. 用户输入：`123456`（明文）
2. 后端将 `123456` 进行MD5加密 → `e10adc3949ba59abbe56e057f20f883e`
3. 与数据库中的MD5值比较：`e10adc3949ba59abbe56e057f20f883e` == `e10adc3949ba59abbe56e057f20f883e` ✅
4. 验证通过，登录成功！

## ❓ 常见问题

### Q1: 重新编译后还是显示密码错误？

**可能原因：**
1. 后端服务没有重启
2. 编译失败，新代码未生效
3. 缓存问题

**解决方法：**
1. 确认后端服务已重启
2. 检查编译是否有错误
3. 清理并重新编译：
   ```powershell
   mvn clean install
   ```

### Q2: 如何确认 MD5 工具类是否正确？

**测试方法：**
可以在后端代码中添加测试代码，或使用在线MD5工具验证：
- 输入：`123456`
- MD5值应该是：`e10adc3949ba59abbe56e057f20f883e`

### Q3: 其他医生账号也无法登录？

**检查：**
1. 确认所有医生的密码在数据库中都是MD5格式
2. 确认数据库初始化脚本已正确执行
3. 可以在数据库中查看密码字段：
   ```sql
   SELECT username, password FROM doctors;
   ```
