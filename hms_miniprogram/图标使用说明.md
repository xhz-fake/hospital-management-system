## 🎨 图标规格说明

### TabBar 图标
- **尺寸**: 81px × 81px
- **格式**: PNG（支持透明背景）
- **未选中颜色**: #7A7E83（灰色）
- **选中颜色**: #0b988f（主题青绿色）

### 功能图标
- **尺寸**: 150px × 150px 或 80px × 80px
- **格式**: PNG
- **背景色**: 主题色 #0b988f 或透明
- **图标色**: 白色或主题色

### 医院卡片
- **尺寸**: 750px × 360px
- **格式**: PNG
- **背景色**: 主题色 #0b988f
- **用途**: 首页轮播图、医院信息页面

## 🔧 如何重新生成图标

### 方法一：使用 Python 脚本（推荐）

```bash
cd hms_miniprogram
python create_icons.py
```

脚本会自动：
1. 检查并安装 Pillow 库（如果未安装）
2. 创建所有目录结构
3. 生成所有图标文件

### 方法二：使用 HTML 生成器

1. 在浏览器中打开 `generate_icons.html`
2. 点击"生成所有图标"按钮
3. 下载生成的图标文件
4. 将下载的文件移动到对应的 `assets` 目录下

### 方法三：使用设计工具

如果需要更精美的图标，可以使用以下工具：

- **Figma**: 免费在线设计工具
- **Photoshop**: 专业图像处理软件
- **IconFont**: 图标字体库
- **Flaticon**: 免费图标资源库

## 📝 图标替换指南

如果需要替换某个图标：

1. **准备新图标**
   - 确保尺寸符合要求
   - 格式为 PNG
   - 支持透明背景（如需要）

2. **替换文件**
   - 找到对应的图标文件
   - 用新图标替换原文件
   - 保持文件名不变

3. **验证**
   - 在微信开发者工具中重新编译
   - 检查图标是否正常显示
   - 测试不同状态下的显示效果

## 🎯 图标设计建议

### 颜色规范
- **主题色**: #0b988f（青绿色）
- **未选中色**: #7A7E83（灰色）
- **背景色**: #ffffff（白色）
- **文字色**: #333333（深灰色）

### 设计原则
1. **简洁明了**: 图标应该清晰易懂
2. **一致性**: 保持统一的设计风格
3. **可识别性**: 在不同尺寸下都能清晰识别
4. **适配性**: 适配不同设备屏幕

### 图标类型
- **TabBar 图标**: 简单线条图标，支持选中/未选中状态
- **功能图标**: 可以稍微复杂，使用填充样式
- **信息图标**: 简洁的图形化表示

## ⚠️ 注意事项

1. **文件路径**: 确保图标文件路径与 `app.json` 和页面代码中的路径一致
2. **文件大小**: 图标文件不宜过大，建议单个图标 < 50KB
3. **图片格式**: 使用 PNG 格式，支持透明背景
4. **命名规范**: 使用小写字母和连字符，保持命名一致性

## 🐛 常见问题

### 问题 1: 图标不显示
**解决方案**:
- 检查文件路径是否正确
- 确认文件是否存在于指定目录
- 检查文件格式是否为 PNG
- 在微信开发者工具中清除缓存后重新编译

### 问题 2: 图标显示模糊
**解决方案**:
- 确保图标尺寸符合要求
- 使用高清图标（2x 或 3x 分辨率）
- 检查图片压缩质量

### 问题 3: TabBar 图标颜色不正确
**解决方案**:
- 检查 `app.json` 中的 `color` 和 `selectedColor` 配置
- 确保图标文件支持透明背景
- 验证图标颜色是否符合设计要求
