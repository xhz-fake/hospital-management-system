# 医院管理系统 - 医生端

Vue3 + Vite + Element Plus 构建的医生管理端系统。

## 技术栈

- Vue 3.3+
- Vite 5.0+
- Element Plus 2.4+
- Vue Router 4
- Pinia 2
- Axios
- ECharts (可选)

## 快速开始

### 安装依赖

```bash
npm install
```

### 启动开发服务器

```bash
npm run dev
```

### 构建生产版本

```bash
npm run build
```

## 功能模块

- **登录**: 医生登录系统
- **工作台**: 数据概览、今日预约列表
- **预约管理**: 查看和管理所有预约
- **患者管理**: 查看和管理患者信息
- **排班管理**: 查看排班信息
- **病历管理**: 管理电子病历
